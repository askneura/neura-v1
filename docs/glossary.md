# Glossary

Key terms used across Neura.

> Reference documentation. V1 contracts are unaudited and not deployed. Read the [security limitations](../SECURITY.md); descriptions are not guarantees.

| Term | Meaning |
|---|---|
| **AMM** | Automated market maker — a pool that prices trades by formula |
| **Invariant (k)** | The value a pool's formula must never decrease |
| **LP token** | Your share of a pool |
| **Pip** | 0.0001% — the unit for fees |
| **Surge fee** | Extra fee on later swaps in the same block |
| **Price impact** | How much your trade moves the price |
| **Slippage** | Price change between quote and execution |
| **TWAP** | Time-weighted average price |
| **Flash swap** | Receive first, pay within the same transaction |
| **CREATE2** | Deterministic contract address |
| **MEV** | Value extracted by reordering transactions |
| **Impermanent loss** | LP value vs. holding, after a price change |
