# Supported networks

The six EVM mainnets Neura supports.

> Reference documentation. V1 contracts are unaudited and not deployed. Read the [security limitations](../SECURITY.md); descriptions are not guarantees.

Neura works on whichever supported network your wallet is already on — no forced switching.

| Network | Chain ID | Native gas token |
|---|---|---|
| Ethereum | 1 | ETH |
| Base | 8453 | ETH |
| Arbitrum One | 42161 | ETH |
| Optimism | 10 | ETH |
| Polygon PoS | 137 | POL |
| BNB Chain | 56 | BNB |

All networks are **mainnets**: transactions use real assets and cannot be undone. Neura V1 will deploy the same contracts at the same CREATE2 addresses on every chain where possible.
