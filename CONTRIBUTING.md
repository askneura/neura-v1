# Contributing to Neura V1

Open an issue for non-sensitive proposals, then submit a focused pull request with rationale and local tests. Keep Solidity pinned to 0.8.28. Explain invariant, accounting, fee and compatibility impacts. Do not claim an audit or deployment that has not happened.

Never commit credentials, wallet signatures, user data, production logs or website implementation. Follow SECURITY.md for vulnerabilities. Check LICENSING.md before redistributing or using source commercially; contribution license terms require clarification from Neura.
